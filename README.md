# IGNITE CUSTOMS — Навчальний вебпроєкт (HTML + CSS + JS)

Це готовий односторінковий сайт студії кастомного автостайлінгу **IGNITE CUSTOMS**, створений на чистому **HTML5**, **CSS3** та **Vanilla JavaScript** без сторонніх фреймворків і збірки. Усі файли містять докладні коментарі з тегами пройдених тем та підказки `СПРОБУЙ ЗМІНИТИ:` для самостійної практики.

## Структура проєкту

```text
car_site/
├── index.html          # Структура сторінки, семантичні теги, форма та модальне вікно
├── styles.css          # Палітра в :root, верстка (Flexbox/Grid), анімації, адаптив
├── app.js              # Робота з DOM: меню, Lightbox, валідація, JSON-пакет для сервера
├── README.md           # Інструкція для учня та чекліст до Практичної роботи №4
└── assets/
    └── cars/           # 7 оптимізованих зображень 16:9 з латинськими назвами
```

> **Чому картинки лежать в `assets/cars/`?**  
> Початкові файли з Viber мають кирилицю та пробіли у назвах (`изображение_viber_...jpg`). На реальному веб-сервері (Linux / GitHub Pages) кирилиця й пробіли в URL часто викликають помилки `404 Not Found`. Тому для сайту створені чисті копії латиницею у форматі 16:9.

## 6 завдань «Спробуй змінити сам»

1. **Зміни кольорову тему за 10 секунд:** у [styles.css](styles.css) у блоці `:root` заміни `--accent-orange: #ff5a1f;` на `#22c55e` (зелений неон) або `#facc15` (жовтий).
2. **Онови шапку та Hero:** у [index.html](index.html) зміни назву бренду, заголовок `<h1>` або цифри в блоці `.hero-metrics`.
3. **Додай власне фото в галерею:** поклади нову картинку (латиницею, наприклад `supra.jpg`) у `assets/cars/`, додай її опис у масив `PROJECTS` в [app.js](app.js) та розкоментуй шаблон кнопки в [index.html](index.html).
4. **Прискор або сповільни анімації:** зміни `--anim-speed` у [styles.css](styles.css) або час `2.2s` у `.status-dot`.
5. **Перевір адаптивність у браузері:** натисни `F12` → іконка телефону/планшета (`Ctrl+Shift+M`) → перевір вигляд на ширині `390px` (iPhone) та `768px` (планшет).
6. **Подивись «Клієнт → Сервер» у дії:** заповни форму запису на сайті, натисни **«Надіслати заявку»** і відкрий вкладку **Console** у DevTools (`F12`) — там з'явиться готовий JSON-пакет заявки.

## Практична робота №4: «Розміщення сайту на сервері» (GitHub Pages)

Щоб опублікувати сайт в інтернеті безкоштовно:

1. **Підготуй файли для завантаження:**  
   Завантажуй у репозиторій лише те, що потрібно сайту: `index.html`, `styles.css`, `app.js`, `README.md` та папку `assets/`.  
   *(Початкові файли `изображение_viber_*.jpg` у репозиторій можна не додавати — вони не використовуються на сторінці).*
2. **Створи репозиторій на GitHub:**  
   Натисни **New repository** (наприклад, `ignite-customs`, тип **Public**) і завантаж туди файли через **Add file → Upload files** (або через `git push`).
3. **Увімкни веб-сервер GitHub Pages:**  
   Перейди в **Settings → Pages** → у пункті **Build and deployment / Branch** обери `main` і папку `/ (root)` → натисни **Save**.
4. **Перевір результат:**  
   Через 1–2 хвилини GitHub видасть публічне посилання вигляду `https://<твій-нік>.github.io/ignite-customs/`. Відкрий його з комп'ютера й телефону та переконайся, що всі 7 фото завантажилися (`F12 → Network`, статус `200`).

## Наступна тема: «Веб-сервер і база даних. Взаємодія клієнт-сервер»

Коли сайт лежить на **GitHub Pages**, це **статичний хостинг**: браузер надсилає серверу простий `GET`-запит, а сервер просто віддає файли `index.html`, `styles.css`, `app.js` і картинки. Зберегти заявку користувача у постійну пам'ять такий хостинг ще не може.

Щоб заявки з нашої форми `#booking-form` зберігалися назавжди, потрібна зв'язка **Клієнт ↔ Веб-сервер ↔ База даних**:

```text
[Браузер (Клієнт)]  -- HTTP POST (JSON) -->  [Веб-сервер (Backend)]  -- SQL INSERT -->  [База даних]
   форма в index.html                           Python / Node.js / PHP                     SQLite / PostgreSQL
```

1. **Клієнт (`app.js`)** перевіряє поля й збирає об'єкт `bookingPayload` у форматі **JSON** (подивись його в консолі `F12` після відправки форми):
   ```json
   {
     "name": "Олег",
     "contact": "@oleg_gt",
     "car": "Ford Mustang GT",
     "service": "vinyl",
     "reference": "Shelby GT500 — синій глянець, смуги й підсвітка арок",
     "createdAt": "2026-11-24T09:40:00.000Z"
   }
   ```
2. **Веб-сервер** приймає цей JSON через метод `fetch("/api/bookings", { method: "POST", ... })`, перевіряє його ще раз і записує новий рядок у таблицю бази даних `bookings`.
3. **База даних** зберігає всі заявки, щоб адміністратор студії міг переглянути їх у будь-який момент, навіть після закриття браузера.
